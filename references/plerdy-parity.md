# Plerdy-compatible scope

Based on official Plerdy SEO Analyzer 4.35 and Plerdy AI product descriptions
reviewed 2026-07-30.

## Implemented locally

- JS-aware rendered pass through browser control.
- Titles, descriptions, canonical, robots, hreflang and headings.
- Internal/external links, duplicate anchors and rel state.
- Image alt, dimensions, responsive/lazy attributes and resource status.
- Text counts, top terms, stopword share and sentence length.
- Open Graph, X/Twitter metadata and JSON-LD parsing.
- Mixed content and baseline security headers.
- Fetch timing, HTML weight and declared resource counts.
- CMS/technology hints.
- Semantic HTML, E-E-A-T/AEO heuristics.
- Markdown, JSON and standalone HTML export.
- Desktop/mobile screenshots and qualitative UX/CRO pass.
- Prioritized fixes and A/B hypotheses.

## Deliberately not simulated

- Real click heatmaps, session recordings or observed scroll depth.
- Numeric AI-predicted heatmaps without a validated model.
- GA4, Search Console, Ahrefs or Semrush data without authorized connection.
- Backlink/ranking database.
- Guaranteed keyword uniqueness or AI-generated-text detection.
- Real Core Web Vitals from raw HTTP timing.
- Automatic website changes.

These need traffic, external data, specialized models or separate tools.
